This userChrome file makes Firefox tabs look like normal, usable tabs again after the changes introduced by the 'Nova' UI.

![screenshot of tabs](https://raw.githubusercontent.com/pidg/MakeTabsGreatAgain/refs/heads/main/tabs.png)

To install it, go to `about:support` in Firefox, find the location of your Profile Folder, then within that folder create a folder called 'chrome'. 

Place the userChrome.css file into that 'chrome' folder, and restart Firefox.
